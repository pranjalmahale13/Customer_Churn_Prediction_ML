# Customer Churn Prediction Using Machine Learning

This project is about predicting whether a **bank customer is likely to churn (leave the bank)** by analyzing customer details such as personal information, account data, and engagement level.  
The main intention behind this project is to understand and implement a **complete machine learning workflow**, starting from data exploration and ending with model evaluation, using a real-world banking dataset.

---

## Dataset Overview

- **Bank Customer Churn Dataset**
- The dataset includes customer-related information like:
  - Credit score
  - Age and gender
  - Account balance and number of bank products
  - Active membership status
- Target variable: **Exited**
  - `1` → Customer has churned  
  - `0` → Customer is still with the bank  

---

## Project Structure

- `implementation_code.ipynb` – Jupyter Notebook containing the full implementation  
- `Bank-Customer-Churn.csv` – Dataset used for training and testing  
- `README.md` – Project documentation  

---

## Project Workflow

### 1. Data Loading and Understanding
- Loaded the dataset using Pandas
- Reviewed:
  - Dataset size and structure
  - Column names and data types
  - Missing and duplicate values
- Developed a basic understanding of each feature and its role in churn prediction

---

### 2. Exploratory Data Analysis (EDA)
- Analyzed the overall distribution of churned and retained customers
- Studied the impact of different features on churn, including:
  - Age
  - Account balance
  - Credit score
  - Active membership status
- Identified trends and patterns affecting customer retention

---

### 3. Data Preprocessing
- Converted categorical features into numerical format
- Removed irrelevant columns such as customer identifiers
- Applied scaling to numerical features wherever required
- Split the dataset into **training and testing sets**

---

### 4. Model Building
- Trained classification models such as:
  - Logistic Regression
  - Other suitable models for comparison
- Focused on understanding model behavior instead of only chasing higher accuracy

---

### 5. Model Evaluation
- Evaluated the models using:
  - Accuracy score
  - Confusion matrix
  - Classification report
- Compared results to identify the best-performing model

---

## Key Insights

- Older customers show a higher tendency to churn
- Customers with low engagement levels are more likely to leave the bank
- Proper data preprocessing has a significant impact on model performance

---

## Technologies Used

- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  
- Jupyter Notebook  

---

## What I Learned

- How to work with real-world structured datasets
- The importance of exploratory data analysis before modeling
- Building and evaluating classification models
- Understanding customer behavior through data-driven insights
